# Python Data Processing & Network Analysis

## Project Overview

This project uses Python to process structured datasets, manage information, and analyze relationships between geographic locations.

It includes multiple Python modules focused on data management, network parsing, visualization, and software testing.

## Technologies Used
- Python 3
- Dictionaries and Sets
- Tuples and Data Structures
- Regular Expressions
- File Processing
- Pytest

## Project Structure

| File | Description |
|---|---|
| `doctors.py` | Doctor and patient data management |
| `supplies.py` | Supply and network data processing |
| `supplies_visualizer.py` | Data visualization |
| `test_doctors.py` | Unit testing for doctors module |
| `test_supplies.py` | Unit testing for supplies module |
| `data_files/` | Structured datasets |

## Technical Skills Demonstrated

- Python programming and problem-solving
- Data structures and algorithms
- File parsing and data validation
- Software testing and debugging
- Data organization and visualization

## Purpose

This project demonstrates practical Python programming skills through structured data processing, network analysis, and software development.
